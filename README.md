# agent-demo

Codex 多 Agent 配置和资源消耗明细列表筛选页面示例。

## 运行页面

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的本地地址。运行检查：

```bash
npm test
npm run build
```

## 页面范围

- 基于《搜索_筛选》《资源分配》和“资源消耗明细-筛选UI”实现项目名称搜索、高级搜索、筛选标签、分组表格与核时数汇总联动。
- 高级搜索包含任务名称、任务模块、操作人、操作空间、求解资源类型、状态和起始日期范围；项目名称与任务名称最多输入 21 个字符。
- 演示环境可切换认证企业、未认证企业和私有化；未认证企业仅显示基础筛选，云端不展示 GPU，私有化不显示内部/外部标签。
- 时间筛选按**任务起始日期**落在所选区间内计算，区间两端均包含；核时数先求和再四舍五入到四位小数。

这是独立的前端演示，记录位于 `src/data.ts`，均为虚构示例数据。搜索历史仅在当前页面会话中保留；项目打开、权限、后端查询和持久化尚未接入。
