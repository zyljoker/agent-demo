# agent-demo

Codex 多 Agent 配置和资源消耗明细列表筛选页面示例。

## 运行页面

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的本地地址。运行检查：

```bash
npm test
npm run build
```

## 页面范围

- 基于 [`docs/资源消耗明细-搜索筛选-开发需求PRD.md`](docs/资源消耗明细-搜索筛选-开发需求PRD.md) 实现项目名称搜索、高级搜索、筛选标签、分组表格与核时数汇总联动。
- 高级搜索包含任务名称、任务模块、操作人、操作空间、求解资源类型、状态和起始日期范围；状态支持多选，项目名称与任务名称最多输入 21 个字符。
- 明细演示包含项目文件状态、解散空间、成员状态、异常原因提示和缺失数值展示；核时数统一显示四位小数。
- 演示环境可切换认证企业、未认证企业和私有化；未认证企业仅显示基础筛选，云端不展示 GPU，私有化不显示内部/外部标签。
- 时间筛选按**任务起始日期**落在所选区间内计算，区间两端均包含；核时数先求和再四舍五入到四位小数。

这是独立的前端演示，记录位于 `src/data.ts`，均为虚构示例数据。搜索历史仅在当前页面会话中保留；项目打开与路径跳转使用演示提示，真实权限、后端查询和持久化尚未接入。开发任务卡见 [`.codex/agents/dev01_task.md`](.codex/agents/dev01_task.md)，验证结果见 `docs/test-report.md`。
