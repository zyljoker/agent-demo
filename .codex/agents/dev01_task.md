# dev01 资源消耗明细任务卡

## 依据与范围

- 需求：`docs/资源消耗明细-搜索筛选-开发需求PRD.md`，验收 AC1–AC10。
- 当前项目为虚构数据的 React 演示，无服务端、真实企业身份、文件列表或平台路由。
- 本轮交付可独立验证的搜索、筛选、分组、标签、格式和演示状态；真实权限范围与平台跳转需后续接口接入。

## 共享契约

- `Task` 和 `Filters` 在 `src/filtering.ts` 定义。状态筛选为 `TaskStatus[]`；记录状态字段可选，以兼容既有数据。
- 同字段多选取并集，不同字段取交集。时间沿用现有演示约定：按任务起始日期、两端包含。这是演示假设，产品仍需确认。
- 汇总先对筛选结果求和，再四舍五入为固定四位小数；空值不参与求和。
- 筛选草稿与已应用条件分开；搜索提交草稿，清除标签同步两者，重置只清空草稿。
