## 0. 需求概览

### 0.1 背景与目标

在 CAE 仿真云平台的「资源分配」「资源明细」两个页面中，对「资源消耗明细」模块做搜索与筛选能力优化，并重构明细表格的分组展示方式，帮助企业/团队管理员快速定位任务、统计资源消耗。

### 0.2 两个页面、两套数据范围

| 页面 | 统计口径 | 明细数据范围 |
|---|---|---|
| 资源分配页 | 企业级 | 统计使用**当前企业**资源的所有明细 |
| 资源明细页 | 团队级 | 统计使用**当前团队**资源的所有明细 |

> 两个页面的表格、搜索、筛选交互完全一致，仅数据范围（接口入参）不同。开发时建议做成同一组件，通过 props 区分 `scope: 'enterprise' | 'team'`。

### 0.3 三类环境/身份分支（贯穿全文档）

| 分支 | 影响点 |
|---|---|
| 云端 SaaS vs **私有化部署** | 私有化：不显示「内部/外部」标签；用户下拉无二级分组；求解资源类型含 GPU |
| 企业**未认证** vs **已认证** | 未认证：高级搜索仅 3 个字段并显示提示文案；已认证：开放全部 7 个字段 |
| 云端暂未上线 GPU | 求解资源类型中，云端只有 CPU；GPU 仅私有化环境出现 |

### 0.4 页面结构（自上而下）

1. 顶部 Tab：`云资源` / `软件订阅` / `导出额度`（本期不改动逻辑）
2. **总资源**卡片：共享节点（单位：核时）、存储空间（单位：GB）
3. **使用明细**图表：时间-共享节点折线图、时间-存储空间折线图；右上角为时间范围选择 + 统计粒度下拉（按时间统计）
4. **资源消耗明细**（本期核心）：搜索区 + 分组开关 + 已选筛选标签 + 核时数汇总 + 明细表格

## 3. T1 · 数据模型建议（产品侧建议结构，需与后端接口对齐）

### 3.1 明细记录对象 `ConsumptionRecord`

```ts
interface ConsumptionRecord {
  id: string;                       // 任务记录 ID
  projectId: string;
  projectName: string;              // 项目名称（随重命名联动）
  projectFileStatus: 'normal'      // 正常
    | 'in_recycle_bin'             // 在回收站、未彻底删除
    | 'permanently_deleted'        // 已彻底删除
    | 'no_permission';             // 当前用户无可见权限
  taskName: string;                 // 任务名称
  taskModule: TaskModule;           // 任务模块枚举
  space: {
    id: string;
    name: string;                   // 归属空间名称（随改名联动）
    dismissed: boolean;            // 空间是否已解散
  };
  user: {
    id: string;
    name: string;                   // 与组织架构/个人中心同步
    identity: 'internal' | 'external';   // 内部/外部（私有化不展示）
    status: 'active' | 'left_space' | 'account_deleted'; // 在空间/已退出/账号已删除
  };
  startTime: string;                // 起始时间 YYYY-MM-DD HH:mm:ss
  endTime: string;                  // 结束时间
  durationText: string;             // 运行时长（可由起止时间计算）
  cpuCores: number | null;          // CPU 核数
  gpuCount: number | null;          // GPU 块数（历史稿出现，列保留待确认）
  coreHours: number | null;         // 核时数（核*时）
  status: TaskStatus;               // 任务状态
  errorType?: ErrorType;            // 异常类型（status=abnormal 时存在）
  errorMessage?: string;            // 异常气泡文案
  filePath: string;                 // 项目所属路径
  crossSpace: boolean;              // 是否跨空间文件
}
```

### 3.2 枚举定义

```ts
// 任务模块（共 8 项）
type TaskModule =
  | 'geometry'        // 几何
  | 'contact'         // 识别接触
  | 'load_import'     // 导入载荷
  | 'mechanics'       // 力学
  | 'thermal'         // 热学
  | 'optimization'    // 优化设计
  | 'metamaterial'    // 超材料设计
  | 'nurbs';          // NURBS曲面

// 任务状态（下拉全集待确认，目前已知 3 种）
type TaskStatus = 'completed' | 'cancelled' | 'abnormal';
// 已完成 completed | 已取消 cancelled | 异常 abnormal
```

### 3.3 筛选条件对象 `FilterState`（高级搜索面板状态）

```ts
interface FilterState {
  keyword: string;              // 基础搜索（项目名称）
  taskName: string;             // 高级-任务名称
  modules: TaskModule[];        // 任务模块（多选）
  userIds: string[];            // 操作人（多选）
  spaceIds: string[];           // 归属空间（多选，含已解散）
  resourceTypes: ('CPU' | 'GPU')[]; // 求解资源类型（多选）
  statuses: TaskStatus[];       // 状态（多选）
  dateRange: [string | null, string | null]; // 起始/终止时间
}
// 默认值：全部为空、空数组、null
```

## 4. T3 · 资源消耗明细表格

### 4.1 表格列定义（以最新 UI 图为准）

| 列 | 字段 | 说明 |
|---|---|---|
| 项目名称 | projectName | 分组时为项目根节点；未分组时每行显示项目名 |
| 任务名称 | taskName | 具体任务名 |
| 资源使用 | space.name | 原列名「项目归属」**改名为「资源使用」** |
| 用户 | user.name + 标签 | 见 4.5 |
| 起始时间 | startTime | |
| 结束时间 | endTime | |
| 运行时长 | durationText | 见 G5 |
| CPU 核数 | cpuCores | |
| 核时数（核*时） | coreHours | 4 位小数 |
| 状态 | status | 见 4.6 |
| 所属路径 | 路径 Icon | 见 4.4，仅项目根节点显示 |

> **待确认 B1**：历史 UI 稿出现过「任务 ID」「GPU 块数」独立列，最新 UI 图为「CPU 核数」单列 + 路径 Icon。是否保留 GPU 块数/任务 ID 列需确认。

### 4.2 分组展示开关

- 开关**默认勾选（开启分组）**。
- **勾选 = 分组展示**：以项目为维度分组，项目作为根节点行（带展开/折叠箭头），其下展示该项目的任务行；项目默认**全部展开**。
- **取消勾选 = 未分组展示**：取消项目层级，按任务操作逐条平铺，每条任务独立一行。
- 切换分组开关时，当前筛选条件、排序结果保持不变，仅展示形态变化。

### 4.3 排序规则

- **项目排序（分组态）**：按「该项目下最新一条任务的操作时间」**倒序**；项目内一旦有新任务，项目顺序实时重排。
  - 示例：项目 1 最新任务时间为 2025-03-10，项目 2 为 2025-06-10，则项目 2 在上；项目 1 新增一条 2025-08-10 的任务后，项目 1 重排到上方。
- **任务排序**：项目内（分组态）或全表（未分组态）均按任务操作时间**倒序**。

### 4.4 项目名称与路径 Icon

**项目名称点击行为**

| 项目/文件状态 | 行为 |
|---|---|
| 正常 | 点击打开/预览当前项目 |
| 在回收站未彻底删除 / 无可见权限（含审批未通过、被拒绝的上传文件） | Toast：`无法找到此文件` |
| 已彻底删除 | 名称直接显示为「文件已删除」 |
| 跨空间文件（含分享给团队的跨空间文件） | Toast：`请切换至该空间后再打开` |

- 项目重命名后，表格内项目名称**联动更新**。
- 遵循平台「最多同时打开 5 个文件」的规则（超出时按平台既有规则处理）。

**路径 Icon（黄色文件夹图标）**

- 仅在**分组态的项目根节点行**显示；分组后的任务行、未分组态均不显示。
- Hover：气泡显示当前项目的完整文件路径。
- 点击：跳转至项目所在路径；若文件被删除/无权限 → Toast `无法找到此文件`；跨空间 → Toast `请切换至该空间后再打开`。

### 4.5 「资源使用」与「用户」列规则

**资源使用（空间）**
- 显示任务归属空间名称；空间改名后同步更新。
- 空间被解散：名称后追加「已解散」标签。

**用户**
- 用户名与企业组织架构/个人中心设置的名称保持同步。
- 身份标签：`内部`（企业内成员）、`外部`（企业外成员）；**私有化环境不显示这两个标签**。
- 成员被移出当前空间：用户名后显示「已退出团队」；该成员之后重新加入：不再显示该标签。
- 成员账号被删除：用户名后显示「账号已删除」。

### 4.6 状态列

| 状态 | 样式 | 交互 |
|---|---|---|
| 已完成 | 绿色标签 | 无 |
| 已取消 | 灰色标签 | 无 |
| 异常 | 红色标签 + 异常感叹号 Icon | Hover Icon 弹出气泡，展示该任务异常原因（见第 7 节） |

### 4.7 核时数汇总（表格右上角）

- 文案：`核时数（核*时）消耗：XXXX`，数值四舍五入保留 4 位小数。
- **未搜索/未筛选时**：统计当前范围内所有任务的总核时数。
- **搜索/筛选后**：仅统计筛选结果任务的总核时数，随筛选条件实时变化。
- 清除全部筛选后恢复全量汇总。

## 6. T6 · 高级搜索面板

### 6.1 面板标题与认证分支

- 面板标题：`高级搜索`。
- **未认证企业**：仅显示「任务模块、状态、时间」3 个字段，底部常驻提示文案：
  > `提示：认证企业后可解锁更多高级搜索，如：任务名称、操作人、操作空间、求解资源类型`
- **已认证企业**：显示全部 7 个字段，不显示上述提示。

### 6.2 字段规则

| 字段 | 控件 | 默认值/必填 | 选项与规则 |
|---|---|---|---|
| 任务名称 | 文本输入 | 空 / 非必填 | Placeholder `请输入任务名称`；21 字符限制 |
| 任务模块 | 下拉**多选** | 空 / 非必填 | 几何、识别接触、导入载荷、力学、热学、优化设计、超材料设计、NURBS曲面（共 8 项）；Placeholder `请选择` |
| 操作人 | 下拉**多选** | 空 / 非必填 | 见 6.3 |
| 归属空间 | 下拉**多选** | 空 / 非必填 | 同时列出**现存 + 已解散**空间；选项随表格内实际空间动态变化；Placeholder `请选择` |
| 求解资源类型 | 下拉**多选** | 空 / 非必填 | CPU、GPU；**云端仅 CPU，GPU 仅私有化出现** |
| 状态 | 下拉**多选** | 空 / 非必填 | 已完成/已取消/异常（全集待确认 B2）；Placeholder `请选择` |
| 时间 | 起止时间范围 | 空 / 非必填 | 复用平台后台时间选择组件；用于匹配任务起始/结束时间；Placeholder 分别为 `起始时间`、`终止时间` |

### 6.3 操作人下拉的分组逻辑

- **云端**：分组下拉，一级选项为 `全部`、`内部`、`外部`；内部/外部下挂二级成员列表（分别对应表格中带内部/外部标签的成员）。
- **私有化**：仅一级平铺面板，列出当前空间内所有成员，不做内外部分组。
- 下拉成员列表随表格内成员及其数量动态变化。

### 6.4 操作按钮

- **重置**：将面板内所有字段恢复为默认空状态（不触发搜索，仅清空表单；是否同时清空已选标签见 6.5）。
- **搜索**：①关闭面板；②按面板条件筛选明细表格；③在搜索框下方生成已选筛选标签（第 7 节）；④核时数汇总同步刷新。

### 6.5 联动原则（单一数据源）

- 面板表单、已选筛选标签、表格数据、核时数汇总四者共用同一个 `FilterState`，任一处修改都通过同一状态驱动，避免出现面板与标签不一致。

## 8. 异常原因枚举（状态=异常时的 Hover 气泡文案）

> 以下为原稿列出的全部异常类型与文案，前端按 `errorType` 映射对应 `errorMessage`；未命中枚举时兜底显示 `求解异常，详情请进入项目内查看`。

### 8.1 几何报错
- 超过几何限制：解析后文件大小、接触对、几何数量、解析后前端限制（具体超限项由后端给出）
- STL 文件相关：
  - `stl文件不水密`
  - `stl文件非流形`
  - `存在三角形自相交，请检查`
  - `无法打开stl文件，请检查`（文件不存在或文件损坏无法打开）

### 8.2 连接/接触报错
- `不存在接触，请尝试调整参数`（项目树自动接触未识别到接触对）
- `必须仅包含一个分析步`
- `所导入的几何体不包含实体文件`
- `解析json文件时发生错误，请检查json文件文本格式`
- `bin文件格式错误`
- `导入装配体接触数目超过当前版本最大值`
- `识别接触时几何体数量异常`
- `查找接触对时发生错误，请检查几何文件`

### 8.3 导入载荷失败
- `无法打开csv文件`
- `计算导入载荷失败`

### 8.4 NURBS 曲面
- 失败详情输出于 `nurbs输出.txt`（具体气泡文案**待确认 B3**）

### 8.5 分析类任务（力/热/优化/超材料）
- `求解异常，详情请进入项目内查看`

## 9. 验收标准（Given-When-Then，可直接作为测试用例）

### AC1 · 分组/未分组
- **Given** 明细存在多个项目且每个项目下有多条任务，**When** 页面默认加载，**Then** 分组开关为开启态，项目按根节点分组、默认展开，项目按组内最新任务时间倒序、组内任务按操作时间倒序排列。
- **Given** 分组态，**When** 关闭分组开关，**Then** 表格平铺为任务逐条展示，路径 Icon 消失，筛选与排序条件不变。

### AC2 · 核时数格式与汇总
- **Given** 表格存在核时数数据，**When** 渲染任意核时数与汇总，**Then** 全部四舍五入保留 4 位小数；无值显示 `/`。
- **Given** 未做筛选，**When** 查看右上角汇总，**Then** 为全量任务总核时数；**Given** 已筛选，**Then** 汇总仅包含筛选结果且随条件实时变化。

### AC3 · 项目名称与路径
- **Given** 项目在回收站/无权限，**When** 点击项目名或路径 Icon，**Then** Toast 提示 `无法找到此文件`。
- **Given** 项目被彻底删除，**Then** 名称显示 `文件已删除`。
- **Given** 跨空间文件，**When** 点击，**Then** Toast 提示 `请切换至该空间后再打开`。
- **Given** 项目重命名，**When** 重命名成功，**Then** 表格项目名同步更新。

### AC4 · 用户/空间标签
- **Given** 私有化环境，**Then** 不显示内部/外部标签，操作人下拉为一级平铺。
- **Given** 成员被移出空间，**Then** 出现 `已退出团队`；该成员重新加入后标签消失。
- **Given** 空间已解散，**Then** 资源使用列空间名后出现 `已解散` 标签，且该空间仍可在归属空间下拉中被选中。

### AC5 · 输入限制
- **Given** 任意搜索/任务名称输入框，**When** 输入到第 22 个字符，**Then** 第 22 个字符无法输入，最大长度停留在 21。

### AC6 · 高级搜索认证分支
- **Given** 企业未认证，**When** 打开高级搜索，**Then** 仅出现任务模块、状态、时间及认证提示文案。
- **Given** 企业已认证，**When** 打开面板，**Then** 出现全部 7 个字段且无提示文案。

### AC7 · 多选与环境差异
- **Given** 云端环境，**Then** 求解资源类型仅 CPU；**Given** 私有化环境，**Then** 出现 GPU 选项。
- **Given** 面板多选了 3 个成员，**When** 点击搜索，**Then** 搜索框下标签显示 `成员A +2`。

### AC8 · 标签清除联动
- **Given** 已生成多个筛选标签，**When** 点击某标签清除 Icon，**Then** 该条件移除、面板内同步清除、表格与汇总联动刷新。

### AC9 · 重置
- **Given** 高级搜索面板已填写多个条件，**When** 点击重置，**Then** 所有字段恢复为空默认态。

### AC10 · 异常气泡
- **Given** 存在异常任务，**When** Hover 状态标签上的异常 Icon，**Then** 弹出气泡并展示第 8 节中对应的异常原因文案。
